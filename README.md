# Goal to Done

Our task is to build a fullstack application using AI. This is the idea and the basic features of the application we want to build : The idea: An application for people who struggle to turn large, overwhelming goals into manageable tasks. 

How it works: 

Enter a goal, for example, "Build a portfolio website." 

AI breaks it into smaller actionable tasks. 

Users set deadlines and track progress. 

Tasks that are delayed are clearly marked.  
A more detailed version of the feature on how we want the creating of goal should work : 1. The application has a dashboard (see attached file for reference)  with a button for creating your goal project  (form pop up that includes : goal, description, number of participants , deadline --> divide goal into tasks and provide level of priority in each task + roles for each of the participant.  2.
